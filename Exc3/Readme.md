# Список требований

## Требования к безопасности

1. Шифрование данных: передаваемые данные должны быть зашифрованы и переданы по защищенным каналам связи (HTTPS/TLS).
2. Ограничить доступ к API
3. Разработка и внедрение модели RBAC
4. Внедрение логирования и мониторинга действий клиента
5. Произвести аудит безопасности партнера
6. Разработать план реагирования на инциденты системы безопасности
7. Внедрить систему уведомления нарушения безопасности
8. Обеспечить соблюдение 152-ФЗ
9. Обеспечить регулярный адудит прав доступа

## Протоколы аутентификации и авторизации

1. Использовать OAuth 2.0 для взаимодействия между системами.
2. Аутентификация через существующий сервис Keycloak

## Взаимодействие систем

1. RESTful API между мобильным приложением и сервисом умного дома
2. RESTful API между сервисом умного дома и партнерским сервисом.
3. Сервис умного дома имеет внутреннюю БД для хранения конфигом для оптимизации кол-ва запросов к сервису партнеров
4. При изменении конфигурации на стороне партнера отправляется ВебХук в сервис умного дома для актуализации конфигурации системы
